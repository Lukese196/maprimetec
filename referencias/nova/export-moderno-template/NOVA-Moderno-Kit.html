Moderno.

O tema em um arquivo: tokens de claro e escuro, tipografia, controles, superfícies, os efeitos da marca e as receitas de relatório. Use o botão de aparência no topo para ver as duas versões.

Tokens.

Tudo sai de variáveis CSS no <html>. O tema escuro é o mesmo conjunto de nomes com outros valores — nenhum componente sabe qual tema está ativo.

Regra de cor: acentos --a-* para categorias · negativo/reprovado sempre --red · positivo/aprovado --a-blu · um acento por cartão, nunca gradiente de fundo.

Tipografia.

Google Sans é a fonte de produção e não é distribuível: a folha cai para DM Sans, que tem o mesmo desenho geométrico. Peso 700 é o padrão do corpo; apoio cai para 400.
